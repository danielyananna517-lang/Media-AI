# Media AI — 2 minute Vercel deploy

1. Open: https://vercel.com/drop
2. Drag `Media-AI-7.7.0-Vercel-Ready.zip` into the page.
3. Click **Deploy**.
4. After deployment: **Settings → Environment Variables**.
5. Add:
   - Name: `OPENAI_API_KEY`
   - Value: your OpenAI API key
   - Environment: Production
6. Save and **Redeploy**.
7. Open the green/production URL Vercel gives you.

That URL is your real Media AI address.
